# 현장 검증과 운영 전 확인 항목

갱신일: 2026-10-23. 현재 대상은 지도 중심의 **iPhone 설치형 앱**이며 Android는 이전 작업 이력으로 보관합니다. 관광 정보·앱 체험용 QR 퀴즈·사진 관찰·개인 기록을 제공하며 현장 방문이나 XR 이용을 인증하지 않습니다. 관광 자료의 마지막 본문 확인일은 2026-10-22입니다.

| 장소 | 검증할 위치·접근 정보 | 콘텐츠 확인 |

## 확장 7곳

반구대정자·포은대, 모은정, 반고서원 유허비, 울주 대곡리 연로 개수기, 동매산 자연습지, 울산대곡박물관, 천전리 공룡발자국 화석의 콘텐츠 구조는 준비되어 있습니다. 세부 관람 위치·이동 동선 확인 후 미션과 확장 코스를 활성화합니다. 특히 포은대의 바위 또는 하천변 비문으로 직접 접근하는 동선을 만들지 않으며, 천전리 공룡발자국을 향한 임의의 하천 횡단도 안내하지 않습니다.

## 좌표 등록 절차

1. 공식 기관의 위치 자료와 현장 안내판·접근 구역을 대조합니다.
2. 유적 위치와 관광객이 서도 되는 관람 위치를 별도 수치로 기록합니다.
3. 좌표의 원본 출처, 현장 확인 날짜, 확인자를 기록합니다.
4. 코스 구간의 통제·계단·차량 교행·횡단 지점을 검토합니다.
5. 검증된 `viewingPosition`만 길찾기 목적지로 사용합니다. 유적 좌표를 목적지로 대신 사용하지 않습니다.

현재 `OFFICIAL_MAP_ANCHORS`에는 공식 관광 안내에서 확인한 박물관·반구대·천전리의 대표 위치 3개가 있습니다. 시설·유산 대표 위치를 확인된 관람 위치로 승격하지 않습니다. 안전 관람 좌표는 여전히 `null`이며 외부 네이버 지도에는 장소명 검색만 연결합니다. 대표 좌표 출처는 [sources.md](sources.md)에 있습니다.

## 서비스·접근성

- 교통: [울산문화관광재단 순환버스 원본](https://uctf.or.kr/business/tour-mice/smart08)의 운행일·휴무·최종 정류장을 방문일에 재확인합니다. 휠체어·유모차 탑승과 접근 가능 여부는 별도 확인이 필요합니다.
- 공식 QR: 관광 안내의 연결은 서비스 소개 보도자료입니다. 현장 QR에서 얻은 실제 해설 URL을 확인한 뒤 장소별 링크로 교체합니다. 이 링크를 열었다고 퀴즈·방문을 자동 인증하지 않습니다.
- 앱 QR: 퀴즈 해제용 앱 자체 코드와 공식 현장 QR을 구분합니다. 실제 시설에 부착·배포하기 전 운영 주체와 게시 허가·문구를 확인합니다. 공개된 고정 코드는 현장 방문 증거가 아닙니다.
- XR: 도입 안내 링크를 제공하며 운영시간·예약·실사용 자동 인증은 구현하지 않습니다.
- 사진 관찰: 박물관 모형·반구대 관람 구역·천전리의 촬영 가능 범위를 확인합니다. 망원경 접안부 촬영이 불가하거나 그림이 보이지 않으면 촬영 허용 안내판·모형을 사용합니다. 사진·대상 선택·메모는 자기 기록이며 자동 인식 결과로 표현하지 않습니다.
- 안내 사진: 추가 자산은 사용권한이 확인된 사진만 등록하고 저작자·원본·라이선스·변경 내역을 기록합니다.
- 시범 테스트: GPS 거부, 작은 화면, 큰 글자, 미션 건너뛰기, 강한 햇빛, 느린 통신 환경에서 확인합니다.
- 코스: 현재 순서는 방문 추천 순서입니다. 총 거리·시간과 무장애 코스 여부는 측정 후 추가합니다.

## 실제 휴대폰 인수 확인

2026-10-22에는 iPhone 17 Pro / iOS 26.5 시뮬레이터 앱의 빌드·설치·퀴즈 보상·완전 종료 후 기록 보존과 개발 서버 없는 독립 실행을 확인했습니다. 10월 23일에는 제공받은 Client ID와 Ncloud의 Dynamic Map·개발용 Web URL·iOS Bundle ID를 확인했고 브라우저의 실제 지도 타일이 표시됐습니다.

기존 iOS WebView 지도에서 HTTP 요청이 ATS에 차단되는 오류를 확인해 공식 NMapsMap 3.24.0 네이티브 SDK로 전환했습니다. iPhone 17 Pro / iOS 26.5 시뮬레이터 설치·실행에서 인증·실제 지도 타일·공식 마커 3개·유산 위치 보조 설명과 축소 동작을 확인했습니다. 기존 origin과 저장소를 유지했고 수집 배지 1개도 보존됐습니다. [SDK 연결 당시 지도 캡처](ios-naver-map.png)는 화면 전체 레이아웃 변경 전 시뮬레이터 화면입니다.

이후 사용자 요청에 따라 지도를 화면 전체의 배경으로, 투명 WebView의 검색·카드·메뉴를 그 위에 배치했습니다. 최종 시뮬레이터 앱에서 상태 표시줄 뒤부터 하단 끝까지 실제 타일·3개 마커가 채워지고 오른쪽 빈 띠가 제거된 것을 확인했습니다. 확대축소는 왼쪽으로 옮겨 사진 미션과 분리했고, 네이버 로고와 축척도 겹치지 않습니다. [최종 전체 화면 캡처](ios-fullscreen-map.png)는 시뮬레이터 실행 화면입니다. 모달·입력 중에는 지도 화면을 유지하고 상호작용만 차단하는 코드가 있으며, 실제 터치 흐름은 도구 오류로 검증이 남아 있습니다.

좌표 터치 도구의 `noWindowsAvailable` 오류가 반복돼 마커 → 미션·모달 전환은 이번 사용자 흐름 검증을 완료하지 못했습니다. 실제 iPhone 카메라·QR 스캔·GPS·OS 공유와 반복 재실행도 별도 검증 대상입니다. Android는 현재 작업에서 변경·빌드하지 않습니다. 상세 증거는 [구현 현황](implementation-status.md)에 기록합니다.

| 기존 여권 | 메모·사진 수정·제거, 자기 방문 체크 유지, 새 게임과 중복 스탬프 방지, 기존 기록으로 게임 XP를 임의 추가하지 않음 |

| 앱 동작 | 실제 iPhone 최초 실행·완전 종료 후 재실행, safe area, 작은 화면, 중단·재실행, 키보드와 하단 카드 겹침. 10월 22일 시뮬레이터에서 최초 검은 화면 1회가 관찰되어 재현 여부 확인; 이번 ATS 오류와 같은 원인으로 단정하지 않음 |

시뮬레이터에는 실제 카메라가 없습니다. 브라우저 개발 미리보기에서 코드 입력·사진 파일로 확인한 결과를 네이티브 카메라 성공으로 표시하지 않습니다. 앱 데이터 초기화·앱 삭제·기기 변경에 대비한 내보내기와 기록 소실 안내도 확인합니다.

## 기능 확장

현장 QR별 딥링크, 검증된 관람 지점 좌표, 다국어, 검증된 무장애 코스, 선택적 계정 동기화·가져오기, 정식 기관 협업 인증, 예약 API, 실시간 셔틀·XR 연동은 후속 범위입니다. 공식 지원이 확인되지 않은 API나 실물 보상을 가정하지 않습니다. App Store 배포는 개발 빌드와 별도이며 실제 기기·서명·스토어 요건을 확인한 뒤 진행합니다. Android·Google Play 작업은 현재 범위에서 제외합니다.
