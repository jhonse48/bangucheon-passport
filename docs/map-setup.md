# 카카오 지도 연결

확인일: 2026-10-22. 참고: [공식 시작 가이드](https://apis.map.kakao.com/web/guide/), [공식 SDK 문서](https://apis.map.kakao.com/web/documentation/), [공식 장소 검색 예제](https://apis.map.kakao.com/web/sample/keywordBasic/).

## 개발 환경

1. Kakao Developers에서 앱을 만들고 JavaScript 키를 준비합니다. REST API 키나 Admin 키를 프런트엔드에 넣지 않습니다.
2. 해당 키의 JavaScript SDK 도메인에 개발 주소(예: `http://localhost:3000`)와 실제 서비스 도메인을 등록합니다.
3. 프로젝트 루트의 `.env.local`에 다음 값을 넣고 개발 서버를 다시 시작합니다.

```dotenv
NEXT_PUBLIC_KAKAO_MAP_APP_KEY=your_javascript_key
```

배포할 때도 같은 환경 변수를 빌드 환경에 설정합니다. `NEXT_PUBLIC_` 값은 빌드 시 브라우저 번들에 포함되므로 값 변경 후 다시 빌드합니다. JavaScript 키는 브라우저 공개용이며 도메인 제한을 설정합니다.

현장 시연 시 화면의 **지도 연결 설정**을 펼쳐 JavaScript 키를 입력할 수도 있습니다. 이 설정은 해당 브라우저 탭의 `sessionStorage`에만 저장되고 환경 변수보다 우선합니다. 이미 로드된 SDK의 키를 변경하면 페이지를 새로고침합니다. **이 탭의 키 지우기**는 환경 변수 설정으로 돌아갑니다.

## 좌표와 방문 위치

- 좌표가 없는 상태에서도 일러스트, 장소 정보, 미션, 외부 카카오맵 검색 링크를 이용할 수 있습니다. 일러스트에는 실제 지도가 아니라는 표시가 있습니다.
- 목적지 마커는 `viewingPosition`에 유효한 좌표가 있고 `locationStatus`가 `공식 자료 확인`일 때만 생성됩니다. `heritagePosition`은 지도 목적지에 사용하지 않습니다.
- 확인된 관람 좌표가 없으면 장소의 `mapQuery`로 Kakao Places를 검색합니다. 주소가 울산 울주군이며 유효한 좌표를 가진 실제 응답만 사용합니다. 지도는 첫 검색 결과 주변을 보여주며, 검색 결과를 확인된 관람 위치로 표현하거나 목적지 마커로 표시하지 않습니다. 실제 검색 결과 이름과 주소는 접힌 목록에서 확인할 수 있습니다.
- 좌표가 없는 장소에 정적 임의 좌표를 대입하거나 코스 간 경로선을 그리지 않습니다. 검색 결과 주변 지도와 외부 검색은 도보 경로 또는 출입 가능 여부를 보증하지 않습니다.
- 향후 좌표 추가 시 공식 자료의 출처, 확인 날짜, 관람 지점 여부와 안전한 접근 정보를 함께 검증해야 합니다.

## 위치 권한과 오류

현재 위치는 이용자가 **내 위치 표시** 버튼을 누를 때에만 한 번 요청합니다. 관광지 핀과 구별되는 파란 점과 **내 위치** 라벨로 표시하며, 현재 위치 보기 중에는 선택 장소로 복귀하는 버튼을 제공합니다. 장소 선택이 바뀌거나 화면을 떠나면 진행 중인 위치 요청의 늦은 응답은 무시합니다. 현재 위치는 서버로 저장하거나 방문 인증에 사용하지 않습니다. 권한 거부·시간 초과 시 안내를 표시하며 장소 목록은 계속 사용할 수 있습니다.

지도 또는 검색 로딩 실패 시 연결 안내와 외부 검색 링크를 제공합니다. SDK 요청은 12초, 장소 검색은 10초 후 안내 상태로 전환합니다. 브라우저가 구체적인 인증 실패 사유를 노출하지 않을 수 있으므로 앱은 키·도메인·네트워크 확인 항목을 안내하며, 확정하지 않은 원인을 단정하지 않습니다.

실제 지도 동작은 유효한 JavaScript 키와 등록된 도메인에서 확인해야 합니다. 최소 수동 확인: SDK 로드, 검색 주변 표시와 미확인 안내, 검증된 관람 위치 마커 클릭, 위치 허용·거부, 잘못된 키·도메인, 모바일 높이 변화.

`tests/kakao.test.ts`는 유산 좌표 단독 사용 방지, 미검증·잘못된 좌표 제외, 울산 울주군 외 검색 결과 제외, 검색 실패 시 대체 목적지 미생성, 외부 검색어의 안전한 URL 인코딩을 검증합니다. 단위 테스트는 실제 SDK 연결 및 브라우저 위치 권한 테스트를 대신하지 않습니다.
