# 설치형 앱 구현 및 검증 현황

확인일: 2026-10-24. **현재 대상은 지도 중심의 iPhone(iOS) Capacitor 앱**입니다. 사용자 요청에 따라 Android 개발·검증·배포는 현재 범위에서 제외하고 기존 프로젝트는 보관합니다. 새 개인 여정·사진·영상 기능, 13곳 확장, 이전 지도·앱 실행 검증을 날짜별로 구분합니다. 이전 공개 웹 V1의 25개 자동 테스트·홈 화면 브라우저 검증·정적 배포 성공을 현재 버전의 검증 결과로 사용하지 않습니다. 기존 공개 웹 V1은 유지하며 이번 버전을 Sites에 재배포하지 않습니다.

## 날짜별 자동 경로 기록 — 2026-10-24 후속 변경

사용자의 자동 타임라인 요청에 따라 매번 시작·종료하는 기본 흐름을 **자동 경로 기록** 켜기/끄기로 바꿨습니다. 처음에는 꺼져 있으며 이전 수동 여정·사진·미션 보상은 유지합니다. 켜짐 설정과 위치 권한은 별개이고, 앱 밖 기록은 별도 Always 요청으로 안내합니다. 기록은 한국 날짜(Asia/Seoul)별로 보관하며 관광지 밖 이동도 포함합니다.

네이티브 기록 서비스를 WebView 수명주기와 분리하고 AppDelegate에서 복원합니다. 현재·지난 날짜 버퍼를 IndexedDB에 원자적으로 병합한 뒤에만 지난 버퍼의 삭제를 확인합니다. significant-change는 실제 세밀한 경로 점이 아니라 표준 추적 재개 신호입니다. 사용자가 앱을 밀어 강제 종료한 뒤 자동 재실행이나 누락 경로 복원을 보장하지 않습니다.

사진은 여정 버튼·사진 미션 모두 촬영 전에 대상 기록 ID를 확정합니다. 날짜 전환으로 대상이 달라졌다면 다른 날짜에 임의 저장하지 않고 원본 사진 내보내기를 제공합니다. 현재 기록의 영상은 원본을 멈추거나 완료 처리하지 않는 사본으로 만들며, 기존 지도/사진/MP4 형식은 유지합니다. [자동 기록 상세 계약과 iOS 제한](journeys.md)을 참고하세요.

## 이전 검증: 오늘의 여정·GPS 사진·MP4 — 같은 날의 수동 기록 버전

수집함의 ‘사진으로 남긴 발견’·‘나의 여행 메모’ 목록을 **오늘의 여정**으로 바꿨습니다. 기존 장소 기록과 보상은 유지합니다. 지도 바에서 기록 상태·거리·사진 수를 보고 시작·일시정지·다시 기록·종료할 수 있고, 완료 후 지난 여정의 경로·사진을 다시 엽니다. 자세한 데이터 계약과 사용 흐름은 [여정 문서](journeys.md)에 있습니다.

경로는 실제 수신 좌표만 사용하며 A/B 방문 순서 점선·장소 클러스터와 별도 실선으로 표시합니다. 일시정지·120초 초과 GPS 공백은 연결하지 않고, 새 GPS 샘플마다 카메라를 이동시키지 않습니다. 사진 미션에서 남긴 사진도 해당 진행 중 여정에 연결합니다. 촬영 시 유효한 GPS가 없으면 사진만 앨범·영상에 보관하고 관광지 좌표로 대체하지 않습니다.

iOS 추적은 사용자의 시작·재개 동작 뒤에만 실행합니다. 앱 재실행은 일시정지로 복구하며 자동 재개하지 않습니다. 권한 거부·저장 공간 부족 시 기존 기록을 유지하고 오류를 표시합니다. 종료 저장 실패 뒤 남은 네이티브 버퍼, 새 여정 생성 직후 종료, 늦은 촬영 결과와 재시도는 별도 회귀 검사 대상입니다.

완료한 여정을 기기 안에서 **H.264 MP4·720×1280·24fps·20~45초·무음**으로 만듭니다. 최대 좌표 60,000개·사진 60장입니다. 공식 `NMFNaverMapView` 스냅샷이 성공하면 로고·출처 표시를 포함한 전체 지도와 투영 좌표를 사용하고 원래 지도 시점을 복구합니다. 실패하면 명시된 경로 그림으로 전환합니다. ‘사진 앱에 저장’은 Photos 권한을 요청하며 ‘파일로 저장 · 공유’는 OS 공유 화면을 엽니다. 앱 내부 영상 캐시는 여정/전체 삭제에 포함되고 외부에 내보낸 복사본은 별개입니다.

## 이전 검증: 13곳·A/B 코스·관찰 미션 — 2026-10-23

- 기본 지도는 13곳 전체에 맞춥니다. A는 10곳, B는 박물관 출발점을 추가하지 않은 천전리·천전리 공룡발자국·대곡박물관 3곳입니다. 선택 코스의 번호는 방문 순서이고 기본 지도 번호는 1~13입니다.
- 코스 점선은 **방문 순서 연결선이며 실제 보행 경로가 아닙니다.** 코스 변경·해제로 선을 교체/제거하고, 검색·미션 필터와 독립적으로 전체 코스 좌표를 사용합니다. 초기/코스 변경의 화면 맞춤 뒤에 장소 선택 이동이 동작합니다.
- 반구대의 종전 북쪽 대표점을 제거했고 암면 유산 좌표와 조망 공간 일대 근사 좌표를 분리했습니다. 정확도가 다른 13개 좌표와 현장 QR 상태는 [조사 근거](exploration-evidence.md)에 기록합니다. 포은대·유허비처럼 매우 가까운 지점은 축척에 따라 마커가 겹칠 수 있습니다.
- iOS는 화면상 가까운 마커를 “몇 곳”으로 묶고 `clusterTap`을 장소 선택 목록에 연결합니다. 묶음은 실제 구성원 좌표 중 하나를 사용하며 원래 장소 좌표·코스선을 바꾸지 않습니다. 선택 장소와 현재 위치는 개별 표시합니다.
- 현장 QR 원본 URL을 아직 확보하지 못했습니다. 사용자가 QR 메뉴에서 장소를 고르고 해설을 확인한 뒤 퀴즈를 엽니다. `guide-confirmation`과 `app-qr` 해제 출처를 구분하며, 해설 자기 확인은 방문·QR 스캔 인증이 아닙니다.
- 13개 퀴즈와 3개 사진 관찰은 해설→관찰→문제/사진→수집으로 연결됩니다. 총 1,400 XP·스탬프13·카드13이며 기존 ID·기록을 유지합니다.

## 과거 기록: 화면 전체 지도 변경 — 2026-10-23, 13곳 확장 전

사용자의 가로·세로 전체 지도 요청에 따라 `NMFMapView`를 화면 전체의 배경으로 배치하고, 투명한 `WKWebView` 위에 검색·필터·장소 카드·하단 메뉴를 표시합니다. iPhone 17 Pro / iOS 26.5 시뮬레이터에서 상태 표시줄 뒤부터 하단 홈 표시줄까지 실제 타일과 당시 대표 마커 3개가 표시되는 것을 확인했습니다. 지도 오른쪽의 빈 띠를 제거했고 하단 카드·메뉴는 지도 위에 작게 배치했습니다.

## 현재 제약과 다음 확인

- **네이버 지도:** 최신 시뮬레이터 앱의 13곳 범위·클러스터 표시를 확인했습니다. A 코스 점선은 클러스터 추가 전 빌드에서 확인했습니다. 최신 네이티브 B·묶음 터치와 지도 제스처·모달 상호작용은 도구 오류로 추가 확인이 필요합니다. [연결 안내](map-setup.md)에 환경별 설정을 구분합니다.
- **키 관리:** `.env.local`은 Git에서 제외합니다. Client Secret은 사용하지 않습니다. 다른 환경에서 키가 없거나 실패하면 중립 연결 안내를 표시하며 가짜 지도 화면을 제공하지 않습니다.
- **관람 위치:** 13개 지도 표시는 공식/공개 대표 위치 또는 근사 위치이며 확인된 출입구·안전 조망 지점이 아닙니다. 대표 위치를 길찾기 좌표로 넘기지 않고 장소명 네이버 검색을 사용합니다.
- **QR:** 앱 체험용 QR 13개는 현장 안내판 QR과 별개입니다. 안내판 사진 확인1·설치/위치 미확인10·조사표 미대상2이며, 개별 QR 원본 URL·현재 작동은 미확인입니다. 장소 선택·해설 자기 확인으로 진행합니다.
- **사진·XR:** 사진·대상·메모는 자기 기록입니다. 실제 기기의 촬영·권한 처리, 현장의 촬영 허용 구역과 XR 운영을 확인해야 합니다.
- **여정·영상:** 실제 iPhone의 보행·잠금·재부팅·권한 변경·배터리와 사진 앱/파일 공유를 확인해야 합니다. 지도 스냅샷 실패 시 경로 그림을 사용하며 가짜 지도나 위치 없는 사진의 좌표를 생성하지 않습니다. [여정 제약과 복구](journeys.md)를 참고합니다.
- **데이터:** 세 저장소·네이티브 GPS 버퍼·영상 캐시의 전체 삭제를 아우르는 단일 트랜잭션은 없습니다. 오류를 표시하며 가져오기·계정 동기화는 아직 없습니다. OS 공유로 외부 저장한 파일은 앱 데이터 삭제와 별개입니다.
- **네이티브 배포:** 10월 23일 공식 지도 SDK를 포함한 빌드·시뮬레이터 설치·지도 실행을 확인했습니다. 실제 iPhone 설치·App Store 배포는 미실시이며 Android는 현재 범위 밖입니다.
- **온라인 기능:** UI는 앱에 포함되지만 지도·공식 링크에는 인터넷이 필요합니다. 서비스 워커·오프라인 지도·오프라인 해설을 제공하지 않습니다.
