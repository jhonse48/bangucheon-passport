# MVP 구현 및 검증 현황

기준일: 2026-10-22. 구현 범위와 자동 검사·브라우저·현장 검증의 결과를 구분합니다. 최종 통합 코드의 자동 테스트 25개, 타입 검사, 린트와 프로덕션 정적 빌드를 통과했습니다.

## 실제로 읽은 기획

- [상위 문서](https://app.notion.com/p/4015258dac46815eb767e8dba878f00e): 샹보르의 해설·시각화, 바스의 위치 탐방, Lanna Passport의 기록·보상을 참고한 통합 관광 흐름과 A/B 구역의 확장안.
- [하위 기획안](https://app.notion.com/p/4015258dac4681789b7bc9f7b046d7ac): 1~11절의 목표, 관광 코스, 지도, 4화면, 체험·미션, 사용자 흐름, MVP 우선순위, 기술·데이터 구조, 개발 단계, 현장 검증, 시범 범위.
- 하위 문서의 시범 범위를 우선해 6개 장소·2개 활성 코스로 구현했습니다. 기존 서비스의 공식 안내를 연결하고 별도 판타지 설정을 만들지 않았습니다. 원본 Notion은 수정하지 않았습니다.

## 구현한 동작

| 범위 | 구현 내용 |
| --- | --- |
| 화면 | 홈·지도·탐험·탐방 여권, 모바일 하단 내비게이션과 데스크톱 탐색 |
| 코스 | 4개 데이터 중 핵심·천전리 2개 활성, 선택·이어하기·진행률·완주 배지 |
| 장소 | 전체 13곳, 시범 6곳에서 미션, 출처·접근 주의·관찰 포인트·공식 링크 |
| 지도 | Kakao SDK 연결·필터·검색·현재 위치 요청·키 설정·연결 실패 대체 화면 |
| 미션 | 선택형 6개, 기록형 2개. 관찰형·해설 연계형·기록형 3종, 오답 재시도·스탬프·수집 카드 |
| 방문 기록 | 자기 방문 체크와 미션 스탬프 분리, 코스 집계 중복 제거 |
| 개인 기록 | IndexedDB 사진·메모·선택 코스 저장, 수정, 장소별·전체 삭제, 사진 포함 JSON 내보내기 |
| 이미지 | 허가가 확인된 실제 사진 3개와 실제 사진이 아닌 것으로 표시한 자체 일러스트 |
| 배포 구조 | Next.js 정적 내보내기 `out/`, 매니페스트·아이콘. 서버·서비스 워커 없음 |

지도 키는 `.env.local`의 `NEXT_PUBLIC_KAKAO_MAP_APP_KEY` 또는 지도 설정의 현재 탭 입력으로 제공할 수 있습니다. 키 없이도 지도 외 관광 기능을 사용할 수 있습니다. 설정 방법은 [map-setup.md](map-setup.md), 실행 방법은 [README](../README.md)에 있습니다.

## 현재 제약

| 항목 | 상태와 다음 조치 |
| --- | --- |
| 실제 지도 | 유효한 Kakao JavaScript 키와 접속 도메인 등록 필요. 키가 없는 환경은 안내·목록 대체 화면 |
| 관람 위치·마커 | 13곳의 두 좌표 필드 모두 `null`. 검증된 목적지 마커 없음. 검색 결과 주변 지도는 안전 관람 지점으로 표시하지 않음 |
| 보행 길찾기 | 외부 장소명 검색 제공. 정확한 관람 위치까지의 도보 목적지·경로는 검증 후 추가 |
| QR | 울산시 서비스 소개로 연결. 현장 개별 음성·시각 해설 URL 미확인 |
| XR | 공식 도입 안내 연결. 현재 운영·예약·실제 사용 자동 인증 없음 |
| 교통 | 공식 원본 시간표 연결. 실시간 차량 위치·운행 API 없음 |
| 확장 콘텐츠 | 7곳과 2개 확장 코스의 데이터 준비. 현장 검증 후 미션·코스 활성화 |
| 기록 | 현재 브라우저에만 보존. 계정 동기화·JSON 가져오기 화면 없음 |
| PWA | 매니페스트만 준비. 서비스 워커·오프라인 캐시·백그라운드 동기화 없음 |
| 공식 인증·보상 | 자기 기록과 선택 미션. 공식 방문 인증·예약 API·실물 보상 없음 |

관광 좌표·동선·QR·XR·이용 가능 여부의 후속 확인은 [field-verification.md](field-verification.md), 정보 근거와 사진 이용 조건은 [sources.md](sources.md)를 참고하세요.

## 자동 검사

| 검사 | 명령 | 최종 통합 상태 |
| --- | --- | --- |
| 타입 검사 | `pnpm typecheck` | **통과** |
| 린트 | `pnpm lint` | **통과** |
| 저장소·진행률·콘텐츠·Kakao 헬퍼 테스트 | `pnpm test` | **25개 통과** |
| 프로덕션 정적 빌드 | `pnpm build` | **통과**, `out/` 생성 |

자동 테스트는 자기 방문과 스탬프 분리, 코스 집계·다음 장소, 중복 보상, 재연결 후 메모·사진 보존, 동시 기록 수정, 사진 내보내기, 장소·전체 삭제, 용량 오류 시 기존 기록 보존, 콘텐츠 참조 무결성과 Kakao 헬퍼를 확인했습니다. 실제 지도 제공자의 SDK와 브라우저 파일 선택창을 이 자동 검사로 검증한 것은 아닙니다.

## 브라우저 확인

[README의 A–D 시나리오](../README.md#수동-인수-확인-ad)를 기준으로 아래 범위를 브라우저에서 확인했습니다.

| 시나리오 | 합격 기준 | 확인 상태 |
| --- | --- | --- |
| A 코스·해설 | 코스 선택부터 장소별 공식 링크까지 이용 | 코스 시작 → 장소 상세 열기와 공식 링크의 `href` 확인. 외부 페이지 전체 이용 과정의 자동 확인은 별도 |
| B 미션·스탬프 | 오답 처리·정답 저장·여권 보상·중복 방지 | 오답에서 보상 없음, 정답에서 보상 지급, 새로고침 후 여권 **1/6** 확인. 중복 방지는 자동 테스트로 확인 |
| C 메모·사진 | 새로고침 보존·수정·사진 제거·삭제·내보내기 | 메모 저장 → 새로고침 → 다시 열어 보존 확인 → 수정·재저장 확인. 사진 첨부 UI는 아래 권한 제한으로 미완료. 사진 저장·삭제·내보내기·용량 오류는 자동 테스트 통과 |
| D GPS 비허용 | 지도 없이 목록·상세·공식 링크 이용, 키 제공 시 권한 거부 처리 | 키·GPS 없는 장소 목록 확인. 세계유산 필터의 2곳과 외부 검색 링크의 정확한 장소명 확인. 실제 SDK·GPS 거부는 키 부재로 미실시 |
| 반응형 | 약 375px 화면과 데스크톱에서 읽기·터치·모달 이용 | **375×812** 모바일 및 데스크톱 홈을 시각 확인. 주요 흐름에서 모달과 탐색 확인 |

사진 첨부 브라우저 자동 확인은 Chrome 확장 프로그램의 **Allow access to file URLs(파일 URL 접근 허용)** 권한 제한으로 막혔습니다. 이 작업을 위해 확장 프로그램 권한을 변경하지 않았습니다. 일반 사용자의 사진 등록 기능 장애로 단정하지 않으며, 브라우저 파일 선택부터 압축까지의 실제 흐름은 추가 확인이 필요합니다.

현장 보행·실제 QR·XR·셔틀 운행 테스트는 브라우저 검증과 별개이며 아직 수행하지 않았습니다.
