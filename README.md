# 반구천 탐험여권

울산 반구천의 관광 정보를 읽고, 선택 미션을 즐기며, 사진과 메모를 디지털 탐방 여권에 남기는 모바일 웹앱 MVP입니다. 로그인 없이 사용할 수 있습니다.

## 시작하기

개발 환경은 **공식 Node.js 24 LTS와 pnpm 12.15.0**을 기준으로 합니다. 이후 버전을 사용하려면 지원 중인 LTS 버전에서 검증해 주세요. [Node.js 공식 릴리스 안내](https://nodejs.org/en/about/previous-releases)에서 24 LTS 상태를 확인했습니다(2026-10-22). 저장소의 `packageManager`는 `pnpm@12.15.0`으로 고정되어 있습니다.

```bash
cd bangucheon-passport
npm install --global pnpm@12.15.0
pnpm install --frozen-lockfile
pnpm dev
```

프로젝트 폴더 안에서 시작했다면 첫 번째 `cd`는 생략합니다. 개발 주소는 **http://localhost:3000**입니다. 개발 서버는 `127.0.0.1`에 바인딩됩니다. 사진·메모는 브라우저의 사이트별 저장소를 사용하므로 `localhost`와 `127.0.0.1`, 포트가 다른 주소는 서로 다른 기록을 갖습니다.

| 명령 | 용도 |
| --- | --- |
| `pnpm dev` | 개발 서버 |
| `pnpm typecheck` | TypeScript 타입 검사 |
| `pnpm lint` | ESLint 검사 |
| `pnpm test` | 진행률·IndexedDB·콘텐츠·Kakao 헬퍼 테스트 |
| `pnpm build` | 프로덕션 빌드 및 `out/` 정적 파일 생성 |
| `pnpm start` | `out/`을 포트 3000에서 미리보기. 먼저 빌드 필요 |

빌드 결과는 Next.js 서버 없이 정적 호스팅으로 제공할 수 있습니다. `file://`로 직접 열지 말고 HTTP(S) 서버로 실행합니다. 코드·콘텐츠·공개 환경변수를 바꾸면 다시 빌드합니다.

## 구현 범위

- **홈:** 탐험 시작·이어하기, 추천 코스, 진행률, 교통·체험 안내.
- **지도:** 카테고리·검색 필터, 선택 장소 카드, Kakao SDK 연결, 사용자 요청 시 현재 위치, 외부 지도 검색. 키가 없을 때는 실제 지도가 아닌 일러스트와 장소 목록을 제공합니다.
- **탐험:** 장소 소개·관찰 포인트·공식 링크, 3종 선택 미션, 정답 판정, 미션 스탬프, 수집 카드.
- **탐방 여권:** 자기 방문 체크와 미션 기록의 구분, 코스 진행률·완주 배지, 사진·메모·수집 도감, 내보내기·삭제.

기본 콘텐츠는 **13개 장소·4개 코스·8개 미션·6개 서비스·13개 수집 카드**입니다. 시범 장소 6곳은 울산암각화박물관, 집청정, 반구서원, 대곡리 공룡발자국 화석, 대곡리 반구대 암각화 조망지점, 천전리 명문과 암각화입니다. **반구대 핵심 관광 코스**와 **천전리 세계유산 탐방 코스**를 활성화했습니다. 자연·역사 심화 코스와 반구천 세계유산 종합 탐방 코스는 확장 준비 상태입니다.

진행률은 코스의 장소별 자기 방문 체크 또는 미션 완료를 기준으로 계산하며 중복 집계하지 않습니다. 스탬프와 수집 카드는 미션을 완료해야 받습니다. 어느 기록도 공식 방문·XR 이용 인증을 뜻하지 않습니다. 미션은 안내 이용의 조건이 아닙니다.

## 지도 키 설정

```bash
cp .env.example .env.local
```

`.env.local`에 Kakao Developers의 **JavaScript 키**를 넣습니다.

```dotenv
NEXT_PUBLIC_KAKAO_MAP_APP_KEY=your_javascript_key
```

카카오 앱의 JavaScript SDK 도메인 설정에 접속할 개발 주소와 배포 도메인을 등록하고 개발 서버를 재시작합니다. `NEXT_PUBLIC_` 값은 클라이언트 번들에 포함되는 공개용 키입니다. REST API 키나 Admin 키를 넣지 않습니다. 정적 배포에서는 빌드 환경에 값을 설정합니다.

화면에서도 **지도 → 지도 연결 설정**에서 키를 입력할 수 있습니다. 이 값은 현재 탭의 `sessionStorage`에만 저장되며 환경변수보다 우선합니다. **이 탭의 키 지우기**를 누르면 환경변수 설정으로 돌아갑니다. 지도 키가 없어도 장소 목록·상세·공식 링크·외부 카카오맵 검색·미션·여권은 이용할 수 있습니다. 자세한 동작과 오류 처리는 [지도 연결 문서](docs/map-setup.md)를 참고하세요.

현재 13개 장소의 유적 좌표와 안전 관람 좌표는 모두 미검증 상태(`null`)입니다. 유효한 키가 있으면 선택 장소의 Kakao 검색 결과 주변을 보여주며, 이를 검증된 관람 지점으로 표시하지 않습니다. 목적지 마커는 향후 공식 근거가 확인된 관람 좌표에만 생성됩니다. 코스 사이의 경로선·확정 거리·소요시간은 표시하지 않습니다. 외부 링크 역시 현재는 **장소명 검색**이며, 정확한 관람 지점까지의 도보 길찾기는 현장 검증 후 연결합니다.

## 기록과 개인정보

- 사진·메모·방문 체크·미션·진행 코스는 이 브라우저의 **IndexedDB**에 저장합니다. 앱 서버에 전송하거나 계정으로 동기화하지 않습니다.
- 위치는 지도의 **내 위치 표시** 버튼을 누를 때만 요청하고 기록에 저장하지 않습니다. 지도 사용 시 Kakao SDK와 외부 사이트에는 해당 서비스의 네트워크 요청이 발생합니다.
- 장소당 사진 1장과 메모를 저장합니다. JPG·PNG·WebP를 지원하고 20MB 이하 파일을 받아 브라우저에서 긴 변 최대 1600px로 압축합니다. HEIC는 JPG로 변환해 등록합니다.
- **탐방 여권 → 기록 내보내기**는 사진의 Base64 데이터까지 포함하는 JSON을 내려받습니다. **이 장소 기록 삭제** 또는 **전체 기록 삭제**로 기록을 지울 수 있습니다. 전체 삭제는 선택 코스도 초기화합니다.
- 브라우저 데이터 삭제·비공개 모드 종료·기기 변경으로 기록을 잃을 수 있습니다. 필요한 기록은 내보내세요. 현재 JSON 가져오기·복원 화면은 없습니다.
- IndexedDB나 저장 용량에 문제가 생기면 오류를 표시합니다. 저장 실패를 성공으로 안내하지 않으며 관광 정보는 계속 읽을 수 있습니다.

## 기획 근거와 기술 구조

연결된 Notion에서 [상위 성공 사례 조사](https://app.notion.com/p/4015258dac46815eb767e8dba878f00e)와 [하위 개발 기획안](https://app.notion.com/p/4015258dac4681789b7bc9f7b046d7ac)의 본문·표·하위 항목을 읽었습니다. 하위 기획안 1~11절과 상위 문서의 관광 코스 확장안을 기준으로 개발했고, 범위가 다를 때는 하위 기획안의 **시범 6곳·2코스**를 우선했습니다. Notion 원본은 읽기 전용으로 사용했습니다.

Next.js App Router, React, TypeScript, Tailwind CSS 도구 체계, Lucide Icons와 자체 CSS를 사용합니다. `next.config.ts`의 `output: 'export'`로 정적 사이트를 생성합니다. 콘텐츠와 기록 모델은 분리되어 있어 이후 DB 이전과 장소 추가가 가능합니다. 웹 앱 매니페스트와 아이콘은 포함했지만 **서비스 워커·오프라인 캐시는 구현하지 않았습니다**. 완전한 오프라인 PWA로 간주하면 안 됩니다.

## 수동 인수 확인 A–D

1. **A — 코스와 해설:** 홈의 **탐험 시작하기** → 활성 코스 선택·시작 → 코스의 장소 열기 → 공식 안내 링크가 새 창으로 열리는지 확인합니다. 돌아와도 코스 선택이 유지되어야 합니다.
2. **B — 미션과 보상:** 암각화박물관 상세에서 **탐험의 첫 장** 미션 → 오답 선택 시 재시도 안내 확인 → 정답인 **바위 표면에 새긴 그림** 선택 → **발견 기록하고 스탬프 받기** → 여권에서 스탬프·첫 발견 카드를 확인합니다. 같은 미션을 다시 열어도 보상이 중복 증가하지 않아야 합니다.
3. **C — 기록 보존과 삭제:** 장소 상세에서 메모·사진을 추가하고 **기록 저장** → 새로고침 → 같은 장소에서 기록 확인·수정 → 사진 제거 후 다시 저장 → 장소 기록 삭제를 확인합니다. 여권의 JSON 내보내기와 전체 삭제도 별도로 확인합니다.
4. **D — 위치 거부와 대체 이용:** 지도 키 없이 장소 필터·상세·공식 링크·외부 검색을 이용합니다. 유효한 키와 등록 도메인이 있다면 **내 위치 표시**에서 권한을 거부하고 안내가 나오는지 확인합니다. 이후에도 장소와 미션은 사용할 수 있어야 합니다. 실시간 지도·브라우저 위치 권한 테스트는 실제 키가 있어야 가능합니다.

자동 테스트 **25개**, 타입 검사, 린트와 프로덕션 정적 빌드를 통과했습니다. 375×812 모바일·데스크톱 홈 화면을 시각 확인했고, 코스 시작·장소 상세, 오답/정답 보상, 새로고침 후 여권과 메모 보존·수정, 키 없는 장소 목록과 필터를 브라우저에서 확인했습니다. 세부 결과와 검증 범위는 [구현 및 검증 현황](docs/implementation-status.md)에 기록합니다.

사진 첨부의 브라우저 자동 확인은 Chrome 확장 프로그램의 **파일 URL 접근 허용** 권한 제한으로 완료하지 못했습니다. 사진 저장·삭제·내보내기·용량 오류 처리는 자동 테스트로 확인했습니다. 실제 Kakao SDK와 GPS 권한 거부는 유효한 지도 키가 없어 실기 검증하지 않았습니다.

## 남은 작업

현장 관람 좌표, 접근 가능 여부·계단·통제, 개별 QR 해설 URL, XR 당일 운영과 이용법, 셔틀 운행과 접근성 확인이 필요합니다. 현재 QR 연결은 공식 서비스 소개이며, XR은 도입 안내입니다. 정식 예약 API, 실제 이용 자동 인증, 실시간 셔틀, 실물 보상, 클라우드 계정, 다국어, 오프라인 지원은 후속 범위입니다. [현장 검증 목록](docs/field-verification.md)을 기준으로 콘텐츠를 확장합니다.
